# 코잡스 친바

구글 폼 응답으로 **시간이 맞고 학년이 섞인 조**를 자동으로 짜주는 웹 도구입니다.
빌드도, 서버도, 설치도 필요 없는 단일 HTML 파일입니다.

## 쓰는 법

1. Google Sheets 응답 시트를 전체 복사해서 붙여넣거나, `파일 › 다운로드 › CSV`로 받은 파일을 올립니다.
2. **이름 열**과 **학년 열**을 고르고, 명단에서 E-board를 체크합니다.
3. `랜덤 배정하고 조 편성으로 →` 를 누르면 조가 짜집니다.
4. **편집 모드**에서 사람을 직접 옮기거나 맞교환할 수 있습니다.
5. **엑셀로 내보내기** 또는 **시트용 복사**로 결과를 가져갑니다.

## 조를 짜는 기준

- 조원 전원이 **가능하다고 체크한 시간대**에 배정합니다.
- 한 조 안의 **학년이 최대한 겹치지 않도록** 섞습니다.
- E-board는 조마다 1명씩 들어가고, 1명이 맡을 수 있는 최대 조 수를 정할 수 있습니다.
- 여러 번 무작위로 시도해서 가장 좋은 조합을 고릅니다 (시도 횟수 조절 가능).

편집 모드에서 색으로 표시되는 의미:

| 색 | 뜻 |
|---|---|
| 진한 초록 | 추천 — 시간도 되고 그 학년이 조에 아직 없음 |
| 연한 초록 | 가능 — 시간은 되지만 학년이 겹침 |
| 노랑 | E-board를 교환하면 상대 조의 시간이 안 맞음 |
| 흐림 | 불가 — 시간이 안 됨 |

## 데이터

모든 처리는 **브라우저 안에서만** 일어납니다. 서버로 전송되는 응답 데이터는 없습니다.
붙여넣은 데이터와 E-board 체크는 `localStorage`에 저장되어 다음에 열 때 그대로 남아 있습니다.

처음 열면 동작을 확인할 수 있는 **예시 데이터**가 들어 있습니다. `비우기`를 누르면 지워집니다.

## 로컬에서 실행

```
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.
